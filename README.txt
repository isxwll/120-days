# 120 DAYS — versão final PWA

Arquivos:
- index.html — aplicativo completo
- manifest.json — configuração para instalação como app
- sw.js — cache/offline básico
- icons/ — ícone Jolly Roger

Para publicar:
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos mantendo as pastas.
3. Ative Settings > Pages > Deploy from a branch > main > /(root).
4. Abra o endereço do GitHub Pages no Safari do iPhone.
5. Compartilhar > Adicionar à Tela de Início.

Os dados deste protótipo são armazenados no localStorage do navegador/dispositivo.
