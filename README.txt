Instalação no iPhone:
1. Publique o repositório no GitHub Pages.
2. Abra o link no Safari.
3. Compartilhar → Adicionar à Tela de Início.
4. Abra pelo ícone do 120 DAYS.

Os dados ficam no armazenamento local do navegador/aparelho. O menu ••• permite backup/exportação, importação e limpeza.
